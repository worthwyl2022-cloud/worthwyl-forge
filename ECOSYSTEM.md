# Ecosystem map

`worthwyl-forge` / WorthWyl Studio is an acquisition-facing creation, operations, and governance surface. It is supporting and non-authoritative.

Studio may propose, collect, transform, assess, visualize, and present. It may not issue canonical authority or receipts, mutate Kernel state directly, redefine Kernel semantics, or treat local state as canonical. The private Kernel authority plane is maintained by `worthwylfoundation-hue`; see the repository's boundary documentation and [`LICENSE`](./LICENSE).
